# ASEL v4 — память, напоминания, календарь и связка Telegram + приложение

В основе — предыдущая версия ASEL v3 Voice. Все пять пользовательских аватаров сохранены.

## Что добавлено
- Долгосрочная память в SQLite: `POST/GET/DELETE /api/memories`. Сохранённые факты автоматически добавляются в контекст Асель.
- Устойчивые напоминания: `POST/GET/DELETE /api/reminders`. Данные переживают перезапуск сервера. Фоновый обработчик проверяет сроки каждые 15 секунд.
- Локальный календарь: `POST/GET/DELETE /api/events`. Временные метки принимаются только с часовым поясом и сохраняются в UTC.
- Команды Telegram: `/remember`, `/memories`, `/forget ID`, `/remind YYYY-MM-DDTHH:MM+05:00 | текст`, `/today`, `/link`.
- Привязка мобильного user ID к Telegram: в Telegram выполнить `/link`, затем в настройках приложения нажать «Связать Telegram» и ввести шестизначный код.
- В приложении добавлено поле ID пользователя и действие привязки аккаунта.

## Важно о напоминаниях
Напоминания, созданные через Telegram, отправляются в тот же Telegram-чат. Напоминания, созданные через мобильный API, пока сохраняются в общей базе, но не получают Telegram-доставку автоматически: для этого нужно расширить мобильный экран выбора канала доставки и связать его с чатом. Push-уведомления Android/iOS в этой версии не реализованы.

## Календарь
Это собственный календарь ASEL в SQLite, не синхронизация Google Calendar. Google OAuth и двусторонняя синхронизация — отдельный следующий этап.

## Запуск
Сохрани `.env` на основе `.env.example`, заполни `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY`, `ASEL_API_SECRET`, затем:
`pip install -r requirements.txt`
`uvicorn main:app --host 0.0.0.0 --port 8000`

Проверка: `GET /health` должен вернуть `version: 0.4.0`.

## Команды Telegram
- `/remember Любит кофе без сахара`
- `/memories`
- `/forget 2`
- `/remind 2026-11-07T18:30+05:00 | Позвонить`
- `/today`
- `/link` — выдаёт код для привязки мобильного аккаунта (10 минут).

## API
Все endpoints кроме `/health` требуют заголовок `X-Asel-Secret`.

- `POST /api/memories` `{ "user_id":"...", "content":"..." }`
- `GET /api/memories?user_id=...`
- `DELETE /api/memories/{id}?user_id=...`
- `POST /api/reminders` `{ "user_id":"...", "text":"...", "due_at":"2026-11-07T18:30:00+05:00" }`
- `GET /api/reminders?user_id=...`
- `DELETE /api/reminders/{id}?user_id=...`
- `POST /api/events` `{ "user_id":"...", "title":"...", "starts_at":"2026-11-08T12:00:00+05:00", "ends_at":null, "notes":"" }`
- `GET /api/events?user_id=...&start_at=...&end_at=...`
- `DELETE /api/events/{id}?user_id=...`
- `POST /api/link` `{ "mobile_user_id":"...", "code":"123456" }`

## Ограничения и безопасность
- Это прототип, а не готовый production-релиз. Используй HTTPS и длинный случайный `ASEL_API_SECRET`; не открывай SQLite-файл публично.
- Мобильный и Telegram аккаунты используют общую историю и память только после успешной привязки через `/link`.
- Напоминания без Telegram chat ID не отправляются. Неудачная отправка оставляет запись для повторной попытки.
- Не реализованы Google Calendar OAuth, iOS/Android push, полноценная пользовательская авторизация и экранный CRUD для всех сущностей.
- Перед реальным использованием протестируй бэкенд, Telegram-доставку и сборки Flutter на целевых устройствах.

## Визуальный образ
Все пять аватаров — варианты одного персонажа. Сохраняй узнаваемые черты лица; одежду, причёску и окружение можно менять.
